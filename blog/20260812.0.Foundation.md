# Stage One: Project Foundation

**Date:** 12 August 2026

## Objective

Today we began development of the project.

The first stage is a communication platform. It will provide text, voice, and video communication.

We designed the system so that it can evolve without requiring changes to its core communication layer.

## Shared Event Model

We established a boundary within the communication system based on typed events.

The communication system produces structured events.

For example:

```text
message.created
participant.joined
participant.left
message.edited
message.deleted
```

We created a shared package for these event definitions:

```text
@d3-arcana/events
```

The server can use these definitions.

The mobile application will also use these definitions when required.

This creates a common contract between system components.

## Event Envelope

Each event has a common structure.

```text
eventId
type
timestamp
conversationId
actorId
payload
```

For example:

```text
message.created

conversationId: conversation-1
actorId: alice

payload:
    messageId: message-1
    content: "Hello, world!"
```

The event records what happened.

The event does not attempt to interpret or assign meaning to what happened.

This distinction is important.

The communication system records events in a consistent format.

## Next Step

The next development step is to connect the event model to real communication.

A user will send a message from the mobile application.

The server will:

1. receive the message;
2. store the message;
3. create a `message.created` event;
4. deliver the event to other participants.

This will create the first complete vertical slice of the system.

The goal is simple:

> **Record human communication in a structured form without changing the natural communication experience.**

This is the foundation for the system.
